# 🎯 Day 5 – Factors & Multiples

## 🧩 Core Concept Focus

- Understanding factors and multiples
- Relationship between HCF and LCM
- Strengthening number theory concepts using loops, modulo, and basic arithmetic

---

# 🏫 Class Questions

## 1. Print All Factors of a Number

**Input:**
```text
N = 24
```

**Output:**
```text
[1, 2, 3, 4, 6, 8, 12, 24]
```

---

## 2. Print All Multiples of a Number up to N

**Input:**
```text
Number = 4
Limit = 30
```

**Output:**
```text
[4, 8, 12, 16, 20, 24, 28]
```

---

## 3. Find the HCF (Highest Common Factor) or GCD of Two Numbers

**Input:**
```text
12, 18
```

**Output:**
```text
HCF = 6
```

---

## 4. Find the LCM (Least Common Multiple) of Two Numbers

**Input:**
```text
12, 18
```

**Output:**
```text
LCM = 36
```

**Input:**
```text
N = 36
```

## 4. Check if a Number is a Perfect Number

**Input:**
```text
N = 28
```

**Output:**
```text
Perfect Number
```

**Note:**
> If the sum of all proper divisors of a number equals the number itself, then it is called a **Perfect Number**.

## 5. Find the HCF and LCM of Three Numbers

**Input:**
```text

```

```text

```

---

## 📚 Learning Outcomes

By the end of this lesson, students should be able to:

- Identify factors and multiples of a number.
- Generate factors and multiples using loops.
- Calculate HCF/GCD using factor-based or Euclidean approaches.
- Calculate LCM using multiples or the HCF relationship.
- Count and sum factors efficiently.
- Recognize perfect numbers.
- Find HCF and LCM for multiple numbers.
